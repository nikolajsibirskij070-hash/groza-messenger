# ГРОЗА — настоящие Web Push уведомления

## Что уже добавлено
- Service Worker: `public/sw.js`
- Подписка браузера через Push API
- Сохранение подписок в Supabase
- Отправка Push всем другим участникам чата через Supabase Edge Function
- Уведомления могут приходить при закрытой вкладке, если браузер/ОС поддерживают Web Push и уведомления разрешены

## ВАЖНО: 3 действия перед публикацией

### 1. Cloudflare Pages → Settings → Environment variables
Добавьте переменную:

`VITE_VAPID_PUBLIC_KEY`

Значение: ваш **PUBLIC** VAPID key.

После изменения переменных сделайте новый Deploy.

### 2. Supabase Edge Function
В уже созданной функции `send-push` полностью замените код файлом:

`supabase/functions/send-push/index.ts`

Затем нажмите Deploy.

Секреты должны быть:
- VAPID_PUBLIC_KEY
- VAPID_PRIVATE_KEY
- VAPID_SUBJECT

### 3. Включите уведомления
Зайдите на сайт → Настройки → включите уведомления → разрешите их в браузере.

## Как проверить
1. Откройте сайт в двух разных аккаунтах/браузерах.
2. На устройстве получателя включите уведомления.
3. Отправьте сообщение с другого аккаунта.
4. Закройте вкладку получателя.
5. Отправьте новое сообщение.

## Ограничения
На iPhone/iPad поведение зависит от версии iOS и браузера/PWA.
На компьютере браузер может быть закрыт, но система и браузер должны поддерживать push-доставку.
