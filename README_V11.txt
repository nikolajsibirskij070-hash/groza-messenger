ГРОЗА v11 — доработка групп

ЧТО ДОБАВЛЕНО
1. В групповых чатах у входящих сообщений отображаются аватар и имя автора.
2. При создании группы показываются только пользователи, с которыми у текущего аккаунта уже есть личный чат.
3. Создатель группы сохраняется отдельно и имеет роль «Создатель».
4. Кнопка «Управление группой» видна только создателю.
5. По нажатию на шапку группы открывается список участников с ролями.
6. Создатель может:
   - менять название;
   - добавлять участников;
   - удалять участников;
   - назначать Администратора / Модератора / Участника;
   - забирать роли.
7. Исправление ограничения message_type для text/image/file оставлено в SQL v11.

ОБЯЗАТЕЛЬНО ДЛЯ УЖЕ РАБОТАЮЩЕГО SUPABASE:
Открой Supabase → SQL Editor → New query.
Скопируй и выполни целиком:
  supabase/v11_group_creator_contacts.sql

После выполнения SQL обнови сайт/перезапусти деплой.
