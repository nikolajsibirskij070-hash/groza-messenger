GROZA v45 — ОПРОСЫ / МЕНЮ СООБЩЕНИЯ / ЗАКРЕПЛЕНИЯ

Сохранены все существующие файлы и функции. Добавлены только исправления:
1. Опросы в группах: более строгая проверка, понятная ошибка Supabase и отправка push после создания.
2. Меню сообщения всегда фиксируется относительно окна браузера внизу, ниже центра, независимо от позиции сообщения; добавлена прокрутка меню при нехватке высоты.
3. Закреплённое сообщение теперь синхронизируется через chat_pins и при нажатии на плашку ведёт к исходному сообщению в чате.
4. SQL v45 повторно/безопасно настраивает тип poll, RLS для chat_pins/poll_votes и Realtime.

ВАЖНО: если опросы всё ещё не создаются, обязательно выполните supabase/v45_polls_pins_menu_fix.sql в Supabase SQL Editor, потому что фронтенд не может сам изменить схему базы.
