GROZA Messenger v47 — окончательное исправление меню сообщения

Что изменено:
- Меню сообщения теперь находится внутри отдельного fixed viewport layer, созданного через portal в document.body.
- Слой занимает весь 100dvh и не зависит от transform/animation/scroll у сообщений, .messages, .chat и других родителей.
- Само меню позиционируется абсолютным bottom-слоем внутри viewport layer, поэтому при выборе сообщения сверху, снизу или после прокрутки оно открывается в одном месте.
- Убрана зависимость позиции меню от координат выбранного сообщения.
- Меню располагается над нижним полем ввода и имеет собственный вертикальный скролл при маленьком экране.
- SQL для этого исправления не требуется.

Примечание: предыдущие функции проекта сохранены.
