ГРОЗА v24 — исправление статуса прочтения

Причина проблемы: если получатель уже находился в открытом чате, новое сообщение добавлялось через Realtime, но mark_chat_read не вызывался. Поэтому read_at оставался пустым и у отправителя показывалась одна галочка.

Исправление: приложение теперь вызывает mark_chat_read сразу при получении нового сообщения в открытом чате. Также SQL включает Realtime UPDATE для messages.

1. В Supabase SQL Editor откройте supabase/read_receipts_fix.sql и выполните весь код.
2. Загрузите обновлённые файлы сайта на GitHub/Cloudflare.
