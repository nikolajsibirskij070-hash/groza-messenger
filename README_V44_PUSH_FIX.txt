ГРОЗА v44 — исправление настоящих Push-уведомлений

Почему v43 мог показывать уведомления только при открытом приложении:
открытая страница могла показывать локальное уведомление, даже если настоящая Push-подписка не сохранялась/не обновлялась.

v44:
- автоматически восстанавливает Push-подписку после запуска, если разрешение уже выдано;
- сохраняет подписку без проблем с upsert по частичному unique index;
- обновляет Service Worker cache до groza-v44.

После загрузки v44:
1. Запустите supabase/v44_push_fix.sql (безопасно).
2. Загрузите сайт и дождитесь Deploy.
3. На iPhone откройте ГРОЗУ с экрана Домой.
4. Откройте настройки ГРОЗЫ и включите уведомления/разрешите их.
5. Закройте приложение и проверьте с другого аккаунта.
