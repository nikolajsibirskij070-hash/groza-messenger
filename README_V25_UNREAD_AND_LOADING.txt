ГРОЗА v25 — непрочитанные сообщения и быстрая загрузка списка

ИСПРАВЛЕНО:
1. Новое сообщение показывает фиолетовый счётчик непрочитанных, как на скриншоте.
2. Счётчик сохраняется после перезагрузки сайта.
3. Счётчик исчезает только после входа в соответствующий чат (сообщения отмечаются прочитанными).
4. При запуске больше не показывается ложное «Нет открытых чатов» до окончания загрузки.
5. Список данных загружается быстрее за счёт параллельных запросов.
